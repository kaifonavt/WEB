Original project

This is an extension of the team’s Multiverse Archive Midterm . Existing articles, artwork, page paths, red/blue color scheme and Bootstrap structure were retained. No downloaded website template was used.

AI assistance

OpenAI ChatGPT/Codex assisted with JavaScript feature implementation, HTML/CSS changes, validation, tests, documentation and report preparation. Team members must review, understand and verify the code they present.

Libraries

  • Bootstrap 5.3.8 — layout, form components and existing accordions (MIT).
  • jQuery 3.7.1 — slideDown/slideUp help, fadeIn feedback, animate scrolling (MIT).

Library copies are included locally in vendor/. License text is in vendor/BOOTSTRAP-LICENSE.txt and vendor/JQUERY-LICENSE.txt.

Characters and artwork

Marvel characters and related artwork: Marvel and their respective creators. DC characters and related artwork: DC and their respective creators. Images are inherited unchanged from the Midterm repository’s media/image directory; no new third-party images were added. Original image-by-image URLs and photographer/artist credits were not included in that repository and must be completed by the team before submission.

Cards without an inherited portrait are text-only. Story images illustrate characters, and are not claimed to be covers of the recommended editions.

Reading data and event examples

Story summaries and beginner guidance were written with AI assistance. Page counts are approximate planning values, not edition-specific bibliographic claims. The reading estimate assumes one page per minute. Events are illustrative, dated relative to today, and bookings are local demonstrations.

Local data

Saved story IDs, completion flags, event IDs and participant counts are kept in this browser using localStorage. Forms do not send data or store contact details. Browser storage may be limited when opening files directly; localhost provides consistent storage across pages.
